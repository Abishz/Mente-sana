# MenteSana

**Plataforma de bienestar y atención psicológica estudiantil**

## Descripción

MenteSana es una plataforma digital diseñada para facilitar a los estudiantes el acceso a servicios de orientación y atención psicológica. Permite consultar información, seleccionar un psicólogo, revisar disponibilidad y gestionar citas de manera clara, discreta y sencilla.

## Objetivo

Reducir las dificultades para acceder a atención psicológica dentro del entorno estudiantil, ofreciendo un medio organizado para consultar el servicio y solicitar una cita sin procesos innecesarios.

- Container / Row / Col (Sistema de rejilla)
- Nav (Barra de navegación)
- Card (Tarjetas de resumen)
- Table (Tabla de gestión de atenciones)
